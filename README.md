# SLE-2: BFS vs DFS Profiling Report

## Course
02AML204 – Introduction to Artificial Intelligence

## Project Description
This project compares Breadth-First Search (BFS) and Depth-First Search (DFS) using a binary tree graph.

The performance is measured using:
- Average execution time in milliseconds
- Number of nodes explored

## Files
- `sle2_bfs_dfs_large.py` – Python implementation and profiling program
- `SLE2_25UAM003_Vivek.docx` – SLE-2 report document

## How to Run
1. Install Python 3.
2. Open a terminal in the folder containing the Python file.
3. Run:

```bash
python sle2_bfs_dfs_large.py
```

## Profiling Method
The program uses Python's `timeit` module and repeats the timing measurement 100 times.

## Note
Update the PRN, name, division, and date in the Word report before submission. Check the measured output on your own computer and update the report if your values differ.
